# MiniShop React — Week 6-8

React + Vite + Tailwind CSS assignment based on the provided Week 6-8 worksheet.

## Requirements covered

- Header, ProductCard, ProductList, Profile components
- Props: name, price, image, category
- State: cartCount, search, products, loading, error
- Events: onClick and onChange
- Product search/filter
- Fake Store API
- Loading state
- Error state: `ไม่สามารถโหลดข้อมูลได้`
- Empty state: `ไม่พบสินค้าที่ค้นหา`
- Tailwind CSS v4 with Vite

## Run

```bash
npm install
npm run dev
```

Open the Local URL printed by Vite, normally http://localhost:5173.

## Build check

```bash
npm run build
```
