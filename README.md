# MiniShop React — Week 9

MiniShop multi-page React application for the Week 9 Routing & Component Architecture assignment.

## Run

```bash
npm install
npm run dev
```

## Routes

- `/` — Home + Featured Products
- `/about` — About MiniShop
- `/products` — All products
- `/products/:id` — Product Detail
- `/profile` — Profile
- Any unmatched URL — Not Found

## Week 9 concepts

- React Router v6
- BrowserRouter
- Routes / Route
- Link / NavLink
- Outlet
- useNavigate
- useParams
- Component Architecture
- MVC Thinking with `models`, `pages`, and `components`
